# FITPULSE PRO - Premium Fitness Portfolio Template

FitPulse Pro is a high-performance, dark-mode portfolio template designed specifically for personal trainers, gym owners, and fitness coaches who want a premium digital presence that converts visitors into clients.

![FitPulse Pro Banner](https://images.unsplash.com/photo-1534438327276-14e5300c3a48?w=1200&q=80)

## ⚡ Key Features

- **Premium Dark Aesthetic**: Modern, high-contrast design with sleek animations.
- **No-DB Admin System**: Manage all site content directly from a secure in-browser dashboard (integrated with JSONBin.io).
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.
- **Conversion-Focused**: Strategic CTAs, Consultation Popups, and WhatsApp integration.
- **Interactive Galleries**: Support for Video (YouTube) and Photo showcases.
- **Transformation Tracker**: Professional layout for client results and proof.
- **Lightweight & Fast**: Built with React 19 + Vite + Tailwind CSS 4.

## 🛠️ Tech Stack

- **Framework**: React 19 (Hooks & Context API)
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 & Framer Motion
- **Icons**: Lucide React
- **Cloud Data**: JSONBin.io (Optional for persistence)

## 🚀 Quick Start

1. **Clone & Install**:
   ```bash
   git clone <your-repo>
   npm install
   ```

2. **Environment Setup**:
   Copy `.env.example` to `.env` and add your JSONBin keys (see [SETUP.md](./SETUP.md)).

3. **Run Dev Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

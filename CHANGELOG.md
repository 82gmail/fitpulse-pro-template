# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-03-14
### Added
- **Centralized Data Engine**: All site content moved to `src/data/` for easier rebranding.
- **Improved Documentation**: Added detailed `DEPLOYMENT.md` and `SELLING.md`.
- **Project Sanitization**: Completely removed personal assets and replaced them with high-quality placeholders.

### Changed
- Refactored `SiteContext` to import data from external configuration files.
- Branding updated to template-neutral "FitPulse Pro".

## [1.0.0] - 2026-03-08
### Added
- Initial release of FitPulse Pro Portfolio Template.
- No-DB Admin Dashboard with JSONBin.io integration.
- Responsive Hero, About, Services, and Gallery sections.
- Integrated WhatsApp lead capture.
